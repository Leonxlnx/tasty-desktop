# Legacy release 0.8.4

This release focuses on agent stability, clear failure recovery, and a more useful work transcript.

## Highlights

- Keeps active work alive through short WebSocket interruptions instead of restarting the local runtime immediately.
- Shows the exact stop reason inline and keeps runtime errors available until dismissed.
- Adds a direct action to reveal the runtime log for troubleshooting.
- Presents progress updates and tool calls in chronological order, then collapses completed activity into a compact Worked section.
- Keeps the final summary, changed files, token usage, and undo action below completed work.
- Adds Edit task to stop active work, clear queued prompts, and return an earlier prompt to the composer.
- Makes model, reasoning, and permission changes transactional so failed updates do not leave stale UI state.
- Allows Kimi to read only its own background-task output log while preserving workspace isolation for every other file.
- Opens supported external links and reveals local files or folders with the native desktop opener.
- Prevents the right rail from covering the composer and preserves usable conversation width.

## Install

Download `Kimi-Code-Desktop-0.8.4-x64-setup.exe` from the release and run it on Windows 10 or Windows 11.

The GitHub release also provides the updater signature, update manifest, and SHA-256 checksums produced by the signed release workflow.

Windows SmartScreen may show an unrecognized-publisher warning because Microsoft Authenticode signing is not configured yet. Tauri updater signatures remain enabled and are separate from Authenticode.
