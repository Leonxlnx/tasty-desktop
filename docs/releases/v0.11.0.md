# Tasty 0.11.0

Tasty 0.11.0 separates durable background reporting from the visible prompt queue and completes the provider-neutral product identity.

## Highlights

- Keeps completed background-task follow-ups internal so they can wake the agent without appearing as queued user prompts
- Hides internal background-task request text from the conversation while preserving the resulting assistant report
- Adds a regression test that keeps real user-queued prompts visible
- Introduces the geometric Tasty `T` mark across the title bar, onboarding, empty state, About screen, web assets, installer, executable, and platform icon sets
- Replaces remaining public product copy and package descriptions with provider-neutral control-panel language
- Documents the product mark, palette, compatibility anchors, and third-party trademark boundary

## Compatibility

The legacy application identifier, single-instance mutex, local data paths, and preference key remain unchanged internally. This preserves existing chats, settings, single-instance behavior, and updater continuity while all user-facing identity remains Tasty.

## Verification

Release candidates must pass the public-source guard, TypeScript and Rust typechecks, all test suites, Rust formatting, source diff checks, and an unsigned local NSIS packaging build. Installation and restart require explicit user approval.
