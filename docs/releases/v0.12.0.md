# Kimi Code 0.12.0

Kimi Code 0.12.0 restores the product as a focused Windows desktop harness for Kimi Code CLI and improves the reliability of everyday coding sessions.

- Uses Kimi as the only supported runtime for new sessions while keeping historical sessions readable.
- Refreshes the workspace, sidebar, composer, activity timeline, and panel interactions with a calmer graphite design system.
- Makes send, stop, queue, and steer behavior predictable, with compact work activity and clearer completion summaries.
- Expands Git workflows with branch search, remote tracking, fetch and prune, partial staging, conflict groups, diffs, push, pull, rename, and delete actions.
- Improves session recovery, terminal output handling, panel resizing, and Windows process error reporting.
- Introduces the Kimi remote-control protocol while retaining compatibility with existing local data and legacy remote credentials.
- Preserves the existing application identifier, updater signing key, and legacy update feed fallback for safe upgrades.
